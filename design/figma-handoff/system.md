# Design System Specification

## Kolory

- `Ink`: `#0F1115` (tekst i kluczowe akcje)
- `White`: `#FFFFFF` (t³a)
- `Accent`: `#B89C6A` (akcent premium)
- `Subtle Fill`: `#F6F6F7` (input/chips)
- `Line`: `#EAECEE` (obramowania)
- `Muted`: `#69707D` (teksty pomocnicze)

## Typografia (Inter)

- H1: 48 / 120% / 600
- H2: 32 / 120% / 600
- H3: 24 / 120% / 600
- Body: 16 / 145% / 400
- Caption: 13 / 135% / 500

## Siatka i spacing

- Grid desktop: 12 kolumn / margines 80
- Grid mobile: 4 kolumny / margines 16
- Skala spacing: 4, 8, 12, 16, 20, 24, 32

## Promienie i obramowania

- Radius sm: 10
- Radius md: 16
- Radius lg: 24
- Border: 1px `Line`

## Komponenty (warianty do Figma)

1. **Buttons**
   - Primary / Secondary / Ghost
   - States: default, hover, pressed, disabled

2. **Input Fields**
   - Text / Search / Coupon
   - States: default, focus, error, filled

3. **Product Card**
   - Image + badge + heart + price + CTA
   - Variant: available / reserved

4. **Top App Bar**
   - Logo + search + actions

5. **Bottom Navigation (mobile)**
   - Shop / Cart / Account

6. **Checkout Panel**
   - Payment selector
   - Shipping selector
   - Promo code input
   - Summary with discount

7. **Account Blocks**
   - Wishlist list
   - Orders table
   - Notifications list

8. **Admin Blocks**
   - KPI cards
   - Order moderation table
   - Promo CRUD form

## Motion

- Duration quick: 220ms
- Splash intro: 1400–1700ms
- Curves: easeOutCubic (wejœcia), easeOut (opacity)
