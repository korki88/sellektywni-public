# Szablony (bezpieczne do commitu)

- **`dotenv.example`** — kopia referencyjna tego samego, co **`.env.example`** w katalogu głównym repozytorium.  
  **Użycie na nowym PC:** skopiuj do `../.. /.env` (dwa poziomy wyżej = root projektu) i dostosuj.

Źródło prawdy dla zmian w zmiennych środowiskowych: edytuj **`/.env.example`** w root, potem zsynchronizuj treść tutaj (albo odwrotnie — trzymaj jedną wersję i kopiuj).
